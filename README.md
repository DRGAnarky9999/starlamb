# 🐑 Starlamb

### Learn. Remember. Master the Word.

Starlamb is an interactive Bible verse learning game designed to turn memorization into a journey.

Instead of simply reading verses over and over, Starlamb breaks Scripture into smaller pieces and challenges you to learn, practice, remember, and ultimately master each passage.

> **Every verse is a journey. Every piece you learn brings you closer to mastery.**

---

## 🌟 What Is Starlamb?

Starlamb is a browser-based learning game centered around memorizing Bible verses.

Verses are divided into smaller sections, allowing you to work through them step by step instead of trying to memorize an entire passage at once.

As you learn, the game tracks your progress and gives you different ways to practice what you've learned.

Your goal is simple:

### Learn the verse.
### Practice the verse.
### Master the verse. ⭐

---

## 🎮 Features

### 📖 Verse Learning

Break Bible verses into manageable pieces and work through them one section at a time.

The game keeps track of how far you've progressed through each verse so you can continue building your memory without losing your place.

### 🧠 Practice & Recall

Learning something is only half the battle.

Starlamb gives you opportunities to practice recalling what you've learned rather than simply reading it.

The more you practice, the stronger your recall becomes.

### ⭐ Mastery System

Each verse has its own progress toward mastery.

As you learn more sections of a verse, your progress is reflected with stars.

Eventually, a fully learned verse can become:

**⭐ Mastered**

### 🗺️ Your Journey

The **Journey** section lets you see your overall progress.

It tracks things such as:

- 📊 Accuracy
- 📖 Verses learned
- 🔥 Streak
- ⭐ Mastered verses
- 📚 Individual verse progress
- 📝 Practice status

Your Journey gives you a bigger picture of how far you've come.

### 🧩 Story Mode

Starlamb also includes interactive story-based learning.

In story challenges, pieces of a story must be placed into the correct order.

Once you've arranged the pieces, you can check your answer and continue through the experience.

### 👤 Profiles

Starlamb supports player profiles so progress can be associated with the player using the game.

Your profile keeps track of your learning progress, attempts, correct answers, and other game state.

### 📈 Progress Tracking

Starlamb keeps track of your performance while you learn.

Your statistics include things such as:

- Total attempts
- Correct answers
- Accuracy
- Current streak
- Verse progress
- Mastered verses

The goal isn't simply to finish a verse.

The goal is to **actually remember it.**

---

## 🌌 The Philosophy Behind Starlamb

Memorization can feel like staring at a brick wall.

Starlamb is built around a different idea:

**Take the wall apart one brick at a time.**

Instead of expecting you to memorize everything immediately, the game breaks the learning process into smaller steps.

Learn a section.

Practice it.

Come back to it.

Build on it.

Eventually, the pieces become the whole verse.

# 🚀 Getting Started

## Play Online

Starlamb is designed to run directly in your web browser.

No installation is required.

Simply open the game and begin your journey.

## 💻 Running Locally

Starlamb is currently built as a browser-based HTML application.

To run it locally:

1. Download or clone this repository.
2. Make sure `index.html` is present in the root directory.
3. Open `index.html` in a modern web browser.

For the best experience, hosting the game through GitHub Pages is recommended.

---

# 🌐 GitHub Pages

This project can be hosted using GitHub Pages.

The repository should have the following basic structure:

```text
Starlamb/
│
├── CNAME
├── README.md
└── index.html
```

`index.html` is the main entry point for the game.

The `CNAME` file is used when connecting the project to a custom domain.
